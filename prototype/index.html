QRender static prototypes

Design studies for the factoid page. Each page is static HTML built from the qjson data of one Wikidata item. No value, label or image on a page comes from anywhere else.

  • Paris (Q90) — place archetype, a data-rich item, English labels.
  • Nairobi (Q3870) — place archetype, 58 statements against the 435 of Paris, Gujarati labels with the English fallback of the label chain.
  • Nelson Mandela (Q8023) — person archetype, English labels. One life on one axis, and 89 awards.
  • Nelson Mandela (Q8023), Tulu — the same page built by the same code with the label language tcy, mul, en. Wikidata holds 7 Tulu property labels and 4 Tulu values for this item; everything else falls back.
  • One Battle After Another (Q117085614) — film archetype, English labels. Scores, a cast strip, crew cards, 23 rating systems, and a hole where the plot should be.
  • One Battle After Another (Q117085614), Malayalam — the same page with the label language ml, mul, en. The film has 53 sitelinks and not one Indic Wikipedia among them, so the structure reads in Malayalam and the article behind it is English.
  • Golden eagle (Q41181), Hindi — taxon archetype. 110 sitelinks, among them Malayalam, Tamil, Bengali and Urdu, but no Hindi article; 39 common names in 36 languages, and not one in Hindi, although India is in the bird's range. (English version.)
  • Moon (Q405), Igbo — astronomical object archetype. The Igbo article is one line. Igbo has labels for most properties but for few values, and the page counts them. An orbit to scale, a map of the Moon, and a 3D model that loads only on request.

Second generation: composed by rule

One program composes each page from the data by rule, with no code for the item: dimensions from the classes of the properties, a colour for each dimension, a scale against the container, a place among peers, the absences that peers make visible, the provenance of each card, and the English lead with labels in the page language above the linked words.

  • Moon (Q405), Igbo
  • Nairobi (Q3870), Gujarati
  • Golden eagle (Q41181), Hindi

Third generation: three layers

Content, composition and design are separate, and the renderer only fills templates. The composition is computed once and is the same in every language.

  • Nairobi (Q3870), English
  • Nairobi (Q3870), Gujarati — the same composition, the Gujarati text layer
  • Paris (Q90), English and Malayalam — the density test: 689 statements
  • Nelson Mandela (Q8023), Tulu — the person layout, with few Tulu labels
  • One Battle After Another (Q117085614), English — the film layout: cast, credits by person, ratings
